CHERS WEBSITE — CART + WHATSAPP ENQUIRY VERSION

PUBLISHING ON GITHUB PAGES
1. Extract the ZIP file.
2. Open the Chers_Website_Generated folder.
3. Upload the CONTENTS of this folder (index.html, styles.css, script.js, README.txt and images folder) to the root of your GitHub repository.
4. Keep the images folder structure unchanged.
5. In GitHub, open Settings > Pages.
6. Select Deploy from a branch, choose main and /(root), then Save.
7. Wait a few minutes and open https://chersbycherith-svg.github.io/chers/

CART AND CHECKOUT
- Customers can add featured products to the cart and adjust quantities or remove items.
- Checkout collects delivery location, wedding date, theme/colour palette and additional notes.
- Submitting checkout opens WhatsApp with the selected items and customer details pre-filled for Chers.
- This is an enquiry checkout, not online payment. Chers confirms prices, availability and delivery with the customer.
- Cart contents are stored only for the current browser session and are not sent to a database.

IMPORTANT
The WhatsApp number is currently set to 919380431760 in index.html and script.js. Verify it before publishing.
Product prices are not displayed; customers are asked to confirm pricing with Chers.
